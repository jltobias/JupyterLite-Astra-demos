# JupyterLite Astra Demos

![A miniature world of mountains, maps, rivers, cities and orbital geometry](../assets/astra-worlds-splash.png)

**See the idea. Change the world. Understand the model.**

Explore 16 browser-executable notebooks and six interactive 3D scenes, inspired by the
[Awesome GPT-6 Astra](https://github.com/magiccreator-ai/awesome-gpt-6-astra) community directory.
These original educational experiments make geospatial reasoning, procedural worlds, motion and
uncertainty visible through small, inspectable mathematical models.

## Learn through linked views

First **observe** a picture, then **predict** what a parameter change will do. **Change** one input,
rerun the cells, and **explain** the result. Compare maps, graphs and 3D views of the same data.
Each notebook supplies a guided experiment, labeled plots and a clear account of its assumptions.

| Learning route | Start with | Continue to |
|---|---|---|
| Motion and systems | Aquarium motion and robot duel | Procedural train, drying, railroad |
| Geospatial thinking | Globe and projections | Terrain, neighborhood, routes, spatial interpolation |
| World creation | Procedural train and neighborhood | Ocean, point cloud, voxels, sunlight |
| Evidence and uncertainty | Glass drying and point-cloud repair | Lorenz chaos and spatial interpolation |

## Run in your browser

Launch JupyterLite, wait for the **Python (Pyodide)** kernel, then select **Run → Run All Cells**.
First use downloads the runtime and packages. No API key, map account or local Python installation
is needed. Keep `astra_utils.py` beside the notebooks. Use saved plots for reading; execute animation
cells for interactive players. Players begin paused and support scrubbing.

The [World Lab](https://jltobias.github.io/JupyterLite-Astra-demos/demos/) needs no kernel and offers
terrain, a city, globe routes, ocean waves, a voxel island and Lorenz trajectories. Each scene links
to its notebook. Orbit with a pointer or arrow keys and zoom with a wheel or `+` / `−`.

## Scope and attribution

These are educational reinterpretations and extensions, not reproduced creator projects or model
benchmarks. Cities, terrain and sensor data are synthetic. A rendering does not establish geographic
accuracy, and toy water, atmosphere and routing models are not operational forecasts.
Running these examples does not invoke GPT-6 Astra or any model API.

Creator and catalog links appear in every relevant notebook. The repository
[README](https://github.com/jltobias/JupyterLite-Astra-demos) lists launch links, sources,
asset provenance, local build instructions and checks.
